# Package architecture and reproducibility

Version 1.1.0; scenario dates fixed in 2026. Synthetic data is authored deterministically; no random generation or model sampling was used. No real customer data. Expected deadlines and boundary cases are hand specified; the private baseline calculates dates independently.
Python 3.12. The default path is the standard library; the Postgres backend adds psycopg in the `postgres` dependency group. uv project and lockfile included. REST was selected for ease of inspection; adding MCP is optional and must not change semantics.
State uses database transactions, approval bound to the draft hash, request idempotency and logical-record uniqueness. The default backend is SQLite so local runs and the stdlib path stay free of drivers. PostgreSQL is selected with `FNOL_DATABASE_URL`, a Secrets Manager secret, or RDS IAM auth (`FNOL_RDS_HOST` and `FNOL_RDS_IAM_AUTH=1`). Append-only revisions, tool payloads, decisions, and trace events are enforced with triggers. Draft body and hash are immutable; status, review id, and outcome can change. The trace is a hash chain ordered under a transaction lock so multiple containers cannot fork it. Record filing is idempotent on the key and unique on the logical loss. Local operator commands simulate human decisions. Tool timeout simulation is an immediate 503, not a sleeping connection. Schema changes are versioned SQL in `deploy/aws/sql/postgres`, applied by `tools/migrate.py`. The old Azure T-SQL scripts are retired and unused.
The live AWS tasks still share those SQLite files from EFS (`fs-035b11da15aa05ed6` mounted at `/mnt/state`). EFS is NFS. SQLite's POSIX locks do not hold across those clients, so concurrent tasks can stall or damage a file. That is the reason for RDS PostgreSQL on the existing db subnets. The SQL Server instance named `fnol` is unused legacy and is not part of this layout. `fnol-tasks` has no egress on 5432, so the data stack adds one rule from that group to the Postgres security group. Step HTTP uses port 8080 behind Cloud Map `fnol.internal`. Ports 8081–8084 are local client defaults only.
Source documents, mock fixtures, labels and baseline are versioned together. Do not edit fixtures during an assessment. Make any approved correction as a new version and publish it consistently.
